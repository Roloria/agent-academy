选型决策

面对具体需求时怎么选

不是越新越好，也不是越火越好。下面是一个经过社区验证的选型矩阵。

场景 首选 备选 关键考量
通用 Agent 应用 LangGraph OpenAI Agents SDK / Pydantic AI 状态化、可调试、生产可信
多 Agent 角色协作 CrewAI AutoGen / MetaGPT API 直观易学、角色清晰
对话流 / 多 Agent 群聊 AutoGen CrewAI 终止条件、可观察对话
RAG 为主的应用 LlamaIndex LangChain + 独立 Agent 层 索引丰富、检索策略多
OpenAI 生态深度集成 OpenAI Agents SDK LangChain OpenAI 集成 原生 Tracing、Handoffs
学习 / 教育 Smolagents BabyAGI 代码量少、易读懂
.NET / 企业环境 Semantic Kernel AutoGen 微软生态、Azure 集成
类型安全 / Python 严谨派 Pydantic AI LangGraph FastAPI 风格、IDE 友好
Prompt 自动优化 DSPy 手动迭代 学术严谨、可量化优化
★
框架不是越多越好

真正的高手能做到"框架无关" —— 在不同需求下选择最合适的栈，甚至混用。Phase 5 时你会学到这一点。
