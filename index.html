五阶段学习周期

从零基础到独立构建

一条经过验证的完整路径。每一阶段的输出都可以直接检验，并通过实战项目串联起来。

PHASE 1 · 入门

认知与心智模型

理解 Agent 的本质、原理与边界。掌握 LLM、提示工程、工具调用等基石概念。

  • ✓ LLM 基础与推理原理
  • ✓ Prompt Engineering 精要
  • ✓ Agent 范式 (ReAct / Plan-Execute)
  • ✓ 工具调用与函数调用机制
⏱ 预计 1-2 周
PHASE 2 · 核心

技能与工具栈

掌握主流框架（LangChain、LangGraph、CrewAI、AutoGen），学会有目的地选型。

  • ✓ LangChain & LangGraph 实战
  • ✓ 多 Agent 协作 (CrewAI/AutoGen)
  • ✓ 向量数据库与 RAG 集成
  • ✓ 记忆系统与会话管理
⏱ 预计 2-3 周
PHASE 3 · 建造

完整项目搭建

把所有模块组合起来。从架构设计、模块开发、测试到部署，完整走一遍工程化流程。

  • ✓ 需求分析与架构设计
  • ✓ Agent 核心循环实现
  • ✓ 工具注册与异常处理
  • ✓ 可观测性与日志系统
⏱ 预计 3-4 周
PHASE 4 · 评估

评估与优化

系统学习 Agent 评估方法论，建立监控体系，掌握提示、推理、控制等多维度优化技巧。

  • ✓ 评估数据集与基准
  • ✓ 性能监控与成本控制
  • ✓ Prompt 与参数调优
  • ✓ 错误分析与闭环改进
⏱ 预计 2 周
PHASE 5 · 交付

独立大型 Agent 项目

综合运用所学，独立完成一个完整的大型 Agent 项目。开源、部署、上线，写入你的作品集。

  • ✓ 从 0 设计架构蓝图
  • ✓ 模块化代码组织
  • ✓ 测试、文档、CI/CD
  • ✓ 部署上线与运维
⏱ 预计 4-6 周
最终目标

交付你的 Agent

完整的大型 Agent 项目 —— 多 Agent 协作 + 工具生态 + 长期记忆 + 自评估 + 部署运维。可以写入简历或上线 SaaS。
