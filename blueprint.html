FastAPI 后端 API

提供 RESTful/SSE/WebSocket 接口，让其他系统能调用你的 Agent。

api.py 
from fastapi import FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()

@app.post("/agent/invoke")
async def invoke(request: AgentRequest):
    result = await agent.ainvoke(request.dict())
    return result

@app.post("/agent/stream")
async def stream(request: AgentRequest):
    return StreamingResponse(
        agent.astream(request.dict()),
        media_type="text/event-stream"
    )

LangGraph 状态机

用 LangGraph 把整个 Agent 系统抽象为有向图。每一个节点是一个动作，边是条件路由。

stateDiagram-v2
  [*] --> 接收输入: 请求
  接收输入 --> 解析意图
  解析意图 --> 路由分发
  路由分发 --> 单Agent处理: 简单任务
  路由分发 --> 多Agent协同: 复杂任务
  单Agent处理 --> 自评估
  多Agent协同 --> 自评估
  自评估 --> 完成: 通过
  自评估 --> 重规划: 未通过
  重规划 --> 多Agent协同
  完成 --> [*]

Master Agent 设计

  • ✓ 接收用户原始请求
  • ✓ 分解为子任务 DAG
  • ✓ 选择合适的 Sub-Agent
  • ✓ 综合多 Agent 结果
  • ✓ 进行最终质量检查

Sub-Agent 设计原则

  • ✓ 单一职责 (Single Responsibility)
  • ✓ 独立的工具集
  • ✓ 独立的 prompt / 系统提示
  • ✓ 可独立测试的接口
  • ✓ 可被复用、可被替换

工具注册与执行

所有工具通过统一注册中心管理。每个工具有名称、描述、参数 schema、执行函数、异常处理。

tools/registry.py 
from typing import Callable
import inspect

class ToolRegistry:
    def __init__(self):
        self._tools: dict = {}

    def register(self, name=None):
        def decorator(fn: Callable):
            tool_name = name or fn.__name__
            self._tools[tool_name] = {
                "name": tool_name,
                "description": inspect.getdoc(fn),
                "parameters": extract_schema(fn),
                "function": fn
            }
            return fn
        return decorator

    def to_openai_tools(self):
        return [self._format_openai(t) for t in self._tools.values()]

registry = ToolRegistry()

@registry.register(name="search_github")
def search_github(query: str, max_results: int = 5) -> list:
    """在 GitHub 上搜索代码仓库。

    Args:
        query: 搜索关键词
        max_results: 返回结果数, 默认 5
    """
    response = requests.get(f"https://api.github.com/search/repositories?q={query}")
    return parse_repos(response.json(), max_results)

from langchain.memory import (
    ConversationSummaryBufferMemory,
    VectorStoreRetrieverMemory

class HybridMemory:
    def __init__(self, llm, vector_store):
        self.short_term = ConversationSummaryBufferMemory(
            llm=llm, max_token_limit=2000
        )

部署方案

让 Agent 真正上线

从单机到云端,有多种部署路径可选。

🖥 本地原型

最快的反馈循环。适合开发阶段和单用户演示。

  • ▸ 直接运行 python main.py
  • ▸ Gradio 启动 localhost:7860
  • ▸ 适合单用户、单 Agent
  • ▸ 无需考虑并发

🐳 Docker 容器

一致环境、易于分发。适合团队和小规模生产。

Dockerfile 
FROM python:3.11-slim

WORKDIR /app
COPY pyproject.toml poetry.lock ./
RUN pip install poetry && \
    poetry install --no-dev
COPY src/ ./src/
COPY main.py api.py ./

CMD ["uvicorn", "api:app", \
     "--host", "0.0.0.0", \
     "--port", "8000"]

☁️ 云端部署

可扩展、高可用。适合生产环境。

  • ▸ Railway / Fly.io: 简单部署
  • ▸ AWS / GCP: 完全可控
  • ▸ Modal / Replicate: GPU 推理
  • ▸ Vercel + Edge: 轻量前端
  • ▸ Anyscale / Modal: 弹状伸缩
