# 🎓 Agent Academy

> 系统化学习 AI Agent 的完整旅程 · 从认知基础到独立搭建大型 Agent 项目

## ✨ 这是什么

Agent Academy 是一个一站式的 AI Agent 学习网站，整合了以下要素：

- **5 个完整学习阶段**的清晰路径（从认知到独立交付大型项目）
- **120+ GitHub 顶级开源项目** 按类别、成熟度精选
- **40+ 实战动手项目** 配套完整代码骨架
- **完整的大型 Agent 项目蓝图**（架构 / 模块 / 部署）
- **25 篇必读论文** + **6 大课程平台** + **6 本核心书目**
- **10+ 社区** + **8 份 Newsletter** 持续跟进前沿

## 🛠 技术栈

- **HTML5 + CSS3 + 原生 JavaScript** —— 零依赖、零构建
- **响应式设计** —— 桌面 / 平板 / 手机全适配
- **现代深色主题** —— 玻璃拟态、渐变、动效
- **Mermaid 图表** —— 知识图谱、架构图、流程图
- **Inter 字体** + 等宽代码字体 (JetBrains Mono)

## 🎯 设计原则

1. **认知先行** —— 在写代码前建立心智模型
2. **从最小到完整** —— 100 行 ReAct → 多 Agent 系统
3. **可执行优先** —— 每个项目都有完整可运行代码
4. **工程化导向** —— 配置 / 测试 / 部署 / 监控全链路
5. **持续跟进** —— 论文 / 项目 / 社区每周更新

## 🎓 学习路径概览

```
Phase 1 (1-2 周) ─→ Phase 2 (2-3 周) ─→ Phase 3 (3-4 周) ─→ Phase 4 (2 周) ─→ Phase 5 (4-6 周)
   认知基础           技能工具栈           完整项目搭建         评估与优化         独立大型项目
   知识体系            框架精通            工程化实践          性能 / 成本优化       从 0 到 1 交付
```
