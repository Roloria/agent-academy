## 🤔 为什么要做 Agent Academy？

> "我读了 50 篇 Agent 教程，怎么还是写不出 Agent？"

市面上的 Agent 教程 90% 都是**碎片化的工具介绍**：今天一个 LangChain 模板，明天一个 RAG 示例。你学了一堆零件，但不知道**怎么组装成一辆完整的车**。

**Agent Academy 是一个例外**——它是一条经过精心设计的**完整学习路径**，每一步都为下一步服务，从认知基础到生产级大型 Agent 项目,每个阶段都有明确的输入、输出和验证标准。

**学习完成后,你将亲手搭建一个完整的、独立的大型 Agent 项目** —— 而不只是又一个 GPT 套壳应用。

## 🗺️ 五阶段学习路径

从下到上,每一阶段都有起点、终点和检验标准:

```
   🎯  Phase 5 ──── 🏆 独立交付大型 Agent 项目 (4-6 周)
       ↑
   ⚙️  Phase 4 ──── 📊 评估与优化 (2 周)
       ↑
   🛠  Phase 3 ──── 🏗 完整项目搭建 (3-4 周)
       ↑
   🔧  Phase 2 ──── 📦 技能与工具栈 (2-3 周)
       ↑
   🧠  Phase 1 ──── 🌱 认知与心智模型 (1-2 周)
```

| 阶段 | 你会学到 | 阶段产出 |
|---|---|---|
| **🧠 Phase 1** | Agent 本质、LLM 原理、Function Calling、记忆系统 | 完整心智地图 + 6 项自检清单 |
| **🔧 Phase 2** | 主流框架深度 (LangChain / LangGraph / CrewAI / AutoGen) | 框架选型决策表 + 自己的 stack |
| **🛠 Phase 3** | 模块化、测试、CI/CD、可观测性 | 一个完整可运行的 Agent 系统 |
| **⚙️ Phase 4** | RAGAS 评估、DSPy 优化、成本控制 | 完整 Eval Pipeline |
| **🎯 Phase 5** | 从需求到部署全流程 | **一个完整、生产级大型 Agent 项目** 🏆 |

完整的路径细节 👉 [看学习路径页](https://roloria.github.io/agent-academy/path.html)

## 🛠 技术栈

```
┌──────────────────────────────────────────────────┐
│  Frontend    HTML5 + CSS3 (原生, 无构建)          │
│  Interactivity  Vanilla JS (131 行, 零依赖)       │
│  Diagrams     Mermaid (知识图谱 / 架构图)         │
│  Design       现代深色主题 + 渐变 + 玻璃拟态       │
│  Deploy       GitHub Pages / Docker / Nginx      │
│  CI/CD        GitHub Actions (推送即部署)         │
└──────────────────────────────────────────────────┘
```

**为什么选择零依赖?** 网站本身就是一个 "AI Agent 学习项目"。它应该:
- 最低的入门门槛 —— 拿到源码就能读懂
- 最大化透明度 —— 没有黑魔法
- 便于二次创作 —— fork 即可添加你的内容

## 💡 给 Agent Academy 用户的建议

### 🎯 关于学习节奏

> 我们观察了大量学习者,总结出几条核心原则:

1. **🚫 不要囤积** —— 与其收藏 100 篇教程,不如认真消化 10 篇
2. **🧪 输出驱动** —— 能展示给别人看的东西,才是真的学会了
3. **👥 找同伴** —— 独自学习很容易放弃,加入社区
4. **⚡ 短周期迭代** —— 不要等"完美计划",先用 v1 上线,再迭代
5. **🚀 发布它** —— GitHub 公开仓库,写下 README,与世界分享

### 📅 推荐时间投入

| 你的目标 | 每周建议 | 完整周期 |
|---|---|---|
| 仅了解 Agent 概念 | 2-3 小时 | 4 周 |
| 搭建一个能用的小 Agent | 5-8 小时 | 8-10 周 |
| 完成完整大型项目交付 | 10-15 小时 | 12-17 周 |
