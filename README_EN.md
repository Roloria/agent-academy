## 🤔 Why Agent Academy?

> "I've read 50 Agent tutorials. Why can't I still build an Agent?"

**90% of AI Agent tutorials out there are fragmented tool introductions**: a LangChain template here, a RAG snippet there. You learn a pile of parts but don't know how to assemble them into a working system.

**Agent Academy is different** — it's a **complete, carefully designed learning path**, where each step feeds into the next. From cognitive foundations to a production-grade large-scale Agent project, every phase has clear inputs, outputs, and validation criteria.

**When you finish, you'll have built a complete, independent, large-scale Agent project** — not just another GPT wrapper.

## 🗺️ The 5-Phase Learning Path

From bottom to top — every phase has a clear start, end, and validation:

```
   🎯  Phase 5 ──── 🏆 Independent large-scale Agent delivery (4-6 weeks)
       ↑
   ⚙️  Phase 4 ──── 📊 Evaluation & optimization (2 weeks)
       ↑
   🛠  Phase 3 ──── 🏗 Complete project build (3-4 weeks)
       ↑
   🔧  Phase 2 ──── 📦 Skills & tool stack (2-3 weeks)
       ↑
   🧠  Phase 1 ──── 🌱 Cognition & mental models (1-2 weeks)
```

| Phase | What You'll Learn | Phase Output |
|---|---|---|
| **🧠 Phase 1** | Agent essence, LLM fundamentals, function calling, memory systems | Complete mental map + 6-item self-check |
| **🔧 Phase 2** | LangChain / LangGraph / CrewAI / AutoGen in depth | Framework selection matrix + your own stack |
| **🛠 Phase 3** | Modularity, testing, CI/CD, observability | A fully runnable Agent system |
| **⚙️ Phase 4** | RAGAS evaluation, DSPy optimization, cost control | Complete eval pipeline |
| **🎯 Phase 5** | End-to-end from requirements to deployment | **A complete, production-grade Agent project** 🏆 |

Full path details 👉 [See learning path page](https://roloria.github.io/agent-academy/path.html)

## 💡 Advice for Learners

### 🎯 On Learning Rhythm

1. **🚫 Stop hoarding** — Better to deeply digest 10 tutorials than collect 100
2. **🧪 Output-driven** — What you can show others, you've truly learned
3. **👥 Find peers** — Solo learning is hard; join a community
4. **⚡ Iterate quickly** — Ship v1 first, then improve
5. **🚀 Publish it** — Public GitHub repo + README = your portfolio

### 📅 Suggested Time Investment

| Your Goal | Weekly | Total Cycle |
|---|---|---|
| Just understand Agent concepts | 2–3 hours | 4 weeks |
| Build a working small Agent | 5–8 hours | 8–10 weeks |
| Deliver a full large-scale project | 10–15 hours | 12–17 weeks |
